# GTA5 AutoPilot

GTA V Enhanced 多途经点导航原型。游戏原生 NPC AI 负责底层驾驶，项目负责地点队列、导航控制和驾驶风格设置；下一阶段目标是接入自然语言指令，并逐步支持澄清、失败反馈与执行中修改任务。

**状态更新：2026-10-22。此次仅更新文档，没有修改代码，也没有在 Windows / GTA V 中重新验证。**

## 项目定位与职责

```text
用户自然语言
  → LLM 提取意图、地点及顺序（待验证）
  → 程序校验、从地点库映射坐标、管理任务队列
  → GTA V 原生 AI 驾驶 API
  → 游戏执行结果
  → 状态反馈与下一步决策（下一阶段）
```

- 底层驾驶使用 `TASK_VEHICLE_DRIVE_TO_COORD_LONGRANGE`。NPC 的道路选择、避障、转向等能力不是本项目训练或实现的驾驶算法。
- LLM 的初始职责是语义解析，不是生成转向、油门或道路级最优路径。地点序列不等于道路路径规划。
- 地点坐标由程序查询可信地点库，不能让模型凭空编造坐标。未知或多义地点需澄清。
- 当前适合称“导航控制原型”；自然语言链路跑通后可称“LLM 驱动的导航助手”。只有模型实际根据环境反馈调整操作，才进一步体现 Agent 的自主决策能力。
- 当前设计没有让模型理解游戏画面，不宣称 VLM、VLA、端到端视觉导航或自研自动驾驶算法。

## 下一阶段的行为目标（尚未完成）

先把固定流程做可靠，再让 LLM 参与有限的决策；不一次性扩展成大型 Agent 框架。

| 情况 | 目标处理方式 | 不应发生的行为 |
| --- | --- | --- |
| 未知地点、多义地点、相互矛盾的指令 | 提示具体不确定项，必要时给出候选，等用户澄清；保留原任务 | 随便选一个地点、编造坐标、静默丢弃部分地点 |
| 模型不可用、超时或输出格式错误 | 显示错误，不修改原队列，允许重新输入或地图选点 | 将错误当作空任务或悄悄启动部分路线 |
| TCP 断开或指令被拒绝 | 区分发送、接收确认和执行状态，显示失败原因 | 把 socket 写入成功显示为任务完成 |
| 长时间无进展 | 结合可获得的状态判断“疑似停滞”，允许有限重试；超过上限等待用户 | 无限重试、把等红灯直接判成失败、把卡住记成到达 |
| “再加一站海滩” | 明确追加到哪里，显示更新后的剩余顺序 | 误覆盖原路线 |
| “不去机场了，改去医院” | 明确替换范围，不确定是否保留后续站点时询问；更新后返回新顺序 | 把否定中的机场当作新目的地，或仍执行旧目标 |
| “停下 / 取消”或紧急停止键 | 优先中断；取消后的旧异步解析结果不得重新启动导航 | 等待模型完成才停，或旧任务覆盖新任务 |

首版恢复动作建议限制为：重试一次、询问用户、明确授权后跳过当前站、修改目的地、停止。具体停滞时间阈值需在 Windows 实测后确定，避免把某个帧数误认为固定秒数。

建议上层区分 `idle / executing / waiting_for_user / succeeded / failed / cancelled`；这些是拟议语义，不是当前协议已支持的状态。回传至少应能关联任务、当前站点、结果和错误原因；旧任务的迟到结果不能影响新任务。

| 场景 | 验收预期 |
| --- | --- |
| “先去机场，再去海滩” | 地点顺序正确；发送、加载、实际到达分别有证据 |

| 行驶中“取消机场，改去医院” | 替换范围明确，旧目标不再继续执行 |
| 解析未返回时取消，随后旧结果到达 | 保持取消状态，不恢复导航 |
| 完成全部站点 | 仅实际满足到达条件才报告完成 |

## 安装（原有说明，需 Windows 复核）

1. 安装 Script Hook V + SHVDN Enhanced v3
2. 将 `scripts/` 目录下的所有文件复制到 `D:\Epic Games\GTAVEnhanced\scripts\`
3. （可选）下载 [Qwen 0.5B GGUF](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF) 模型，放到 `scripts/models/qwen-0.5b-q4.gguf` 用于验证嵌入式 NLU；下载模型不代表链路已跑通

## 键位

| 按键 | 功能 |
|------|------|
| **Num0** | 开关自动驾驶 |
| **Num1** | 继续到下一站 |
| **Num2** | 停止导航 |
| **Num3** | 按住显示途经队列 |
| **Num4** | 驾驶风格 -（更怂） |
| **Num5** | 驾驶风格 +（更猛） |
| **Num6** | NLU 自然语言输入 |
| **小数点 (.)** | 紧急停止 |

## 使用流程

### 添加途经点
1. 打开地图 → 左键点位置 → **Enter 确认** → 关闭地图
2. 标记自动加入队列，小地图 GPS 自动更新
3. 重复以上步骤添加更多途经点

### 开始导航
1. 上车 → **Num0** 开启自动驾驶
2. 到达途经点后自动刹停，屏幕提示 **Num1 继续 / Num2 停止**
3. 到达最终目的地后自动停止

### NLU 自然语言（现有入口，待端到端验证）
1. **Num6** 打开输入框
2. 输入 "去机场然后回家" → 回车
3. 预期解析地名并加入队列；需核验解析结果、加载行为及实际驾驶结果

## 驾驶风格

| 档位 | Aggressiveness | 说明 |
|------|---------------|------|
| Sloth | 0.0 | 保守驾驶配置；实际交通行为需验证 |
| Base | 0.1 | 温和，日常驾驶 |
| Aggressive | 0.15 | 默认配置；交通合规不作保证 |
| Mad Max | 0.2 | 激进，快速变道 |

行驶中随时按 **Num4/Num5** 切换，立即生效。

## TCP 接口

外部程序可通过 TCP 发送 JSON 指令：

```
端口: 21556
```

```json
{"type": "set_waypoints", "waypoints": [{"name": "机场", "x": -1267, "y": 2995, "z": 15}]}
{"type": "command", "action": "continue"}
{"type": "command", "action": "stop"}
```

## 已知问题

- GTA V 同时只能保留一个地图标记，无法在地图内多选途经点（需反复开关地图添加）
- 当前工程的道路节点导航相关实现为 stub；实际驾驶依赖原生 AI，不据此推断所有版本的 API 均不可用
- 选道/绕路行为不可精确控制，受 GTA V AI 内部逻辑限制
